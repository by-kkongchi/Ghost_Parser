# Ghost Member 요구사항 설계서

팀 프로젝트에서 기여도를 투명하게 분석하는 서비스.

## 1. 문제 정의

팀 프로젝트에서 누가 실제로 기여했는지 정량적으로 알기 어렵다.
회의록, 코드, 깃 활동이 흩어져 있어 종합 판단이 불가능하다.

## 2. 핵심 기능

### F1. 문서 업로드 분석

요구사항 문서를 업로드하면 섹션별로 파싱하여 담당자 매핑의 기준 데이터로 사용한다.

### F2. 깃허브 연동

```python
# 코드블록 안의 # 은 heading이 아님 (파서 테스트용)
data = fetch_github_data("owner", "repo")
```

커밋과 PR을 수집하여 팀원별 활동을 집계한다.
